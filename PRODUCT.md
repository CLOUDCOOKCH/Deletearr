# Deletarr

Intelligent media retention and automated library cleanup for Plex administrators and self-hosting/NAS users. Deletarr answers what can safely be removed, why, and the estimated storage impact.

The interface is an operational application. Its primary flow is connect → synchronize → configure rules → simulate → inspect exact scope → approve → execute/reconcile. Safety, evidence and visibility outrank cleanup volume. A single administrator owns all decisions. Default mode is dry-run, and permanence is activated explicitly.

The product integrates with Plex, Radarr, Sonarr and Seerr. Optional integrations carry explicit feature limitations. No fake catalog, analytics, externally loaded fonts or third-party promotional imagery is shipped.
